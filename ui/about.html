About ciXnet

ciXnet is a public software project for practical, resilient community networks. We are building a friendly client and services on top of Reticulum, while staying compatible with the standard network stack.

Our goal is to make independent communication approachable: familiar messaging, useful local networks, and services people can operate themselves. LocNet guidance, name resolution, internet email access, group chat, a library, and a richer HTML experience are part of the wider project direction.

Development preview: identities, direct LXMF messaging, file and image attachments, optional image reduction, camera controls, avatars, and local networking, and standard NomadNet browsing are implemented. Windows and Android preview packages are available for testing. Linux packaging, Android biometric protection, encrypted storage, and the wider service platform are still in development.

Desktop preview

The desktop window uses pywebview (MIT), with the operating system's web engine. Reticulum runs in a separate supervised receiver process. Portable packages retain dependency notices and a build inventory alongside the application.

The service runs on Python 3.12. The Windows window uses Microsoft Edge WebView2 through pywebview 6.2.1; it does not need Chrome. PyInstaller 6.22.3 bundles Python, our code and its dependencies into the portable executable folder. PyInstaller is the packaging tool, not the interface runtime. The shared Linux launcher selects GTK/WebKitGTK.

pywebview uses MIT terms. Python retains its PSF license, and PyInstaller retains its GPL license with a bootloader distribution exception. Original ciXnet code remains MIT-licensed.

Development tooling

The source is formatted with Prettier (MIT) and Ruff (MIT). esbuild (MIT) bundles the readable JavaScript modules into the browser asset. These are build tools, not separate network services or client runtime frameworks.

Identity verification

Windows Hello integration uses Yubico python-fido2 2.2.1. BSD license; included components retain their Apache 2.0 and MPL 2.0 notices. Windows manages fingerprint, face or PIN verification; ciXnet stores only the public verification credential.

Android preview

The Android app uses Android System WebView and Chaquopy 17.2 to run Python 3.12. Chaquopy license (MIT) · Python license · pySerial 3.5 license (BSD). This preview uses Reticulum’s built-in cryptographic provider. The native receiver service handles background reception and notification channels independently of the chat screen.

Phone pairing

Encrypted pairing uses Reticulum Links. Offline QR generation uses qrcode-generator 1.4.4 (MIT license); scanning uses jsQR 1.4.0 (Apache 2.0 license). Camera frames are decoded locally and are not uploaded.
