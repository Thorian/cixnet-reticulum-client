Reticulum Internet gateway

ciXnet gateway

Connect your ciXnet client to Reticulum over the Internet. Your local network and radio interfaces can keep working alongside it.

Connection details

Gateway address
gw.cixnet.org
TCP port
4242
Interface
Reticulum TCP client

This web page and the Reticulum connection use separate ports. Enter the hostname in your client without https://.

In the ciXnet app

  1. Open Settings.
  2. Enable Use ciXnet fallback gateway.
  3. Set the address to gw.cixnet.org and the TCP port to 4242, then save.

These are the default settings. The client uses the fallback when no relay or transport server is reachable. An ordinary nearby peer does not count as a connection server. Internet access is required; mobile data may be used.

You can disable the fallback or change its address and port at any time.

Using another Reticulum client?

Add a TCP client interface in its Reticulum configuration:

[[ciXnet gateway]]
type = TCPClientInterface
enabled = Yes
target_host = gw.cixnet.org
target_port = 4242

Place this entry inside your existing [interfaces] section. Keep your other interfaces.

Offline messages · LXMF propagation

This server can hold encrypted LXMF messages while a recipient is offline. In your client's propagation node or relay settings, enter this destination address:

49ec09143c134d6bb5d8b522c4cefa37

The propagation address is a Reticulum destination hash, not a hostname. First connect to gw.cixnet.org:4242, then select the address above as your LXMF propagation node. Enable mailbox checking or synchronisation in your client to collect waiting messages.

Fresh ciXnet installations include this node by default. Other clients may call this setting a propagation node, propagation server or relay.

ciXnet DNS · .cix names

Add this Reticulum destination in your client's name server settings and assign it the suffix .cix:

48a1ab73497b08453287f12630883de6

ciXnet includes this mapping by default. Existing custom .cix mappings are kept, and you can change or remove it. This is a retdns service over Reticulum; it does not use Internet DNS port 53.

About this gateway

This gateway connects to the wider Reticulum network through CRN, MichMesh and RNS TCP Node Germany 002. It depends on Internet connectivity. Local Reticulum links remain independent. A gateway connection does not itself select an LXMF propagation mailbox or guarantee message delivery.
