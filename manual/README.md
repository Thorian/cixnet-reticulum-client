# Publishing the manual

MANUAL.md and images/ are the shared source for the website and a future PDF. Keep their relative paths intact.

The four Android screenshots were captured on 16 November 2026 using demonstration data. Desktop screenshots are still needed. Capture actual app screens and leave out private messages, keys and active pairing codes.

For the website, preserve heading anchors, captions and image descriptions. Use the main site stylesheet and responsive images. Replace relative links to project documents with their published locations.

For PDF, use A4 or Letter with at least 18 mm margins. Keep phone screenshots around 65–75 mm wide, captions beside their images, and table rows together where possible. Review each rendered page before publishing.
